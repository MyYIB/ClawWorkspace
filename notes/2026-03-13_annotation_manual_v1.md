# 山水画空间重建标注手册 v1

版本：v1.0  
日期：2026-03-13  
适用任务：单图多实例空间位置重建（不含mesh标注）

---

## 1. 标注目标
本手册用于构建以下监督信号：
1. 深度排序（实例对前后关系）
2. 三远层级（近景/中景/远景）
3. 关键锚点（构图与空间先验）

> 原则：优先保证一致性与可重复性，不追求伪精确绝对深度。

---

## 2. 数据前提
每张图像需已有：
- 实例分割 mask（来自 CLP）
- 实例 ID 与类别（山体、树、建筑、舟、云雾等）

标注员在此基础上补充关系标签与锚点。

---

## 3. 深度排序标注规范

## 3.1 标注单位
- 单位是“实例对 (A,B)”
- 标签集合：
  - `A_front_B`（A在前）
  - `A_behind_B`（A在后）
  - `uncertain`（不确定）

## 3.2 标注范围
- 仅标注可能产生空间关系的 pair：
  1) mask 相交或接近
  2) 视觉上有遮挡关系
  3) 距离较近、存在前后歧义
- 不要求全对全标注。

## 3.3 判断规则（按优先级）
1. **遮挡优先**：谁遮挡谁，遮挡者在前。  
2. **轮廓截断**：被截断对象通常在后。  
3. **尺寸与清晰度辅助**：同类中更大/更清晰常在前（仅辅助，不可单独定论）。  
4. **云雾/留白区域**：无法判断时标 `uncertain`，禁止硬猜。

## 3.4 质检规则
- 互斥检查：若 A_front_B，则不能同时 B_front_A。  
- 传递抽检：若 A_front_B 且 B_front_C，优先检查 A_front_C 是否一致。  
- 每批次 10% 双人复标，Kappa < 0.75 需返工。

---

## 4. 三远层级标注规范

## 4.1 标签集合
- `near`（近景）
- `mid`（中景）
- `far`（远景）
- `uncertain`

## 4.2 推荐流程（先区域后实例）
1. 在整图绘制三远分区带（近/中/远）。  
2. 实例按其 mask 主体落点自动赋层。  
3. 人工校正跨层实例。

## 4.3 判断依据
- 近景：细节密、对比强、通常遮挡他物。
- 中景：主叙事层，细节中等。
- 远景：轮廓化、低对比、空气透视明显。

## 4.4 特殊情况
- 大山跨层：允许拆分为“主层 + 次层备注”。训练时以主层为主。  
- 云雾：若仅作氛围且边界模糊，优先 `uncertain`。

---

## 5. 关键锚点标注规范

每图至少标注三类锚点：

1. **视域锚点（Horizon-like）**
- 2~4点，表示整体视域/视平趋势线

2. **层间分界锚点**
- near-mid 分界：2~4点
- mid-far 分界：2~4点

3. **结构线锚点**
- 山脊线/水岸线/主透视引导线关键折点：3~8点

格式：按顺序点击并编号，保存为 polyline/point list。

---

## 6. 文件格式（建议）

```json
{
  "image_id": "xxx",
  "instances": [{"id": 1, "class": "mountain"}],
  "depth_pairs": [{"a": 1, "b": 3, "rel": "A_front_B"}],
  "san_yuan": [{"id": 1, "level": "mid"}],
  "anchors": {
    "horizon_like": [[x,y], [x,y]],
    "near_mid_boundary": [[x,y], [x,y]],
    "mid_far_boundary": [[x,y], [x,y]],
    "structure_lines": {
      "ridge_1": [[x,y],[x,y],[x,y]]
    }
  }
}
```

---

## 7. 标注流程（作业顺序）
1. 加载实例 mask 和 ID  
2. 标三远分区并赋实例层级  
3. 标关键锚点  
4. 标深度排序 pair  
5. 运行自动一致性检查  
6. 提交复核

---

## 8. 产能建议
- 熟练标注员：
  - 深度排序：40~80 图/天（按复杂度）
  - 三远+锚点：80~120 图/天

---

## 9. 常见错误
1. 把“画面上方”直接当“远景”（错误，必须结合语义与遮挡）  
2. 云雾区域强行判前后（应标 uncertain）  
3. 忽略跨层大对象（需主层+备注）

---

## 10. 验收最低标准
- 有效标签率（非 uncertain）≥ 70%（按任务可调）
- 互斥冲突率 < 1%
- 双标一致性 Kappa ≥ 0.75
