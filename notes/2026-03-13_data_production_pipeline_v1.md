# 山水画空间重建数据生产流水线 v1

版本：v1.0  
日期：2026-03-13  
目标：为“实例空间位置重建（无mesh监督）”与“MIDI迁移学习”构建训练数据

---

## 0. 总体思路
采用“自动预标 + 人工校正 + 质检闭环”的三级流水线：

1. **L0 原始层**：图像 + CLP实例mask  
2. **L1 关系层**：深度排序、三远层级、锚点  
3. **L2 高质层**：小规模精标子集（含粗深度/高可信关系）

---

## 1. 数据分层与规模建议

## 1.1 训练主集（L1）
- 规模：5k~20k 图
- 内容：
  - 实例mask/类别（已有）
  - 深度排序（局部pair）
  - 三远层级
  - 关键锚点

## 1.2 高质量微调子集（L2）
- 规模：500~2000 图
- 内容：
  - L1全部标签
  - 粗深度图（单目深度生成 + 人工修正）
  - 高可信关系图（前后/遮挡/邻接）

## 1.3 验证集/测试集
- 规模：各 300~800 图
- 按风格与复杂度分层抽样（古画/现代、稠密/稀疏）

---

## 2. 生产流程（逐步）

## Step A：样本筛选与去重
1. 汇总候选图像。  
2. 去重（感知哈希 + 相似度阈值）。  
3. 清理低质量样本（过模糊、严重压缩、无主要对象）。

产出：`dataset_raw/`

## Step B：自动预标
1. 从 CLP 读取实例 mask/类别。  
2. 自动生成关系候选：
   - 左右关系（x中心）
   - 邻接关系（mask距离）
   - 遮挡候选（边界交互）
3. 自动给出三远初始建议：
   - 基于 y位置、清晰度、对比度的启发式打分

产出：`prelabels/*.json`

## Step C：人工校正（核心）
1. 修正深度排序（仅关键pair）。  
2. 修正三远层级。  
3. 标关键锚点（视域、层间分界、结构线）。

产出：`labels_l1/*.json`

## Step D：一致性检查（自动脚本）
检查项：
- 关系互斥冲突
- 缺失标签
- 三远层级与锚点矛盾
- mask id 与标签 id 不匹配

不合格样本打回重标。

## Step E：高质子集构建（L2）
1. 从 L1 按复杂度抽样 500~2000 图。  
2. 生成粗深度（现有单目模型）。  
3. 人工轻修深度层次与关系冲突。

产出：`labels_l2/*.json`, `depth_l2/*.png`

## Step F：数据切分与版本化
- `train/val/test` 固定切分，严禁泄漏。
- 版本命名：`v1.0-l1`, `v1.0-l2`, `v1.1...`
- 每版附统计报告与质检报告。

---

## 3. 给方案一（自训练网络）的数据接口

训练最小字段：
- image
- instance masks + classes
- depth_pairs
- san_yuan_level
- anchors

可选增强字段：
- pseudo depth
- relation graph

---

## 4. 给方案二（MIDI迁移）的数据接口

迁移最小字段：
- image
- instance tokens（来自mask与类别）
- relation labels（前后、左右、邻接）
- san_yuan tokens（near/mid/far分布）

高质微调额外字段：
- anchor map
- pseudo depth map

---

## 5. 质量控制（必须）

## 5.1 人工层
- 双标抽检比例：10%
- 一致性阈值：Kappa >= 0.75

## 5.2 自动层
- 冲突率 < 1%
- 缺失关键字段率 < 0.5%

## 5.3 训练层 smoke test
- 用 200 图快速训练 1~2 epoch，检查 loss 是否收敛
- 若不收敛，优先排查标签一致性而不是调模型

---

## 6. 时间规划（可执行）

第1周：
- 标注规范冻结
- 工具链搭建
- 500图试标与返修

第2~3周：
- L1批量标注
- 每3天做一次质检回流

第4周：
- L2高质子集制作
- 首版训练与评估

## 8. 最小可运行闭环（MVP）
1. 先做 1000 图 L1。  
2. 其中 200 图做 L2。  
3. 跑方案一 baseline，验证 depth order / san-yuan 两项指标。  
4. 再把同一批数据接到 MIDI 迁移做对照实验。
