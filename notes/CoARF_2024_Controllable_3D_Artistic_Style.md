# CoARF: Controllable 3D Artistic Style Transfer for Radiance Fields

## 基本信息
- 标题：CoARF: Controllable 3D Artistic Style Transfer for Radiance Fields
- 作者：Deheng Zhang, Clara Fernandez-Labrador, Christopher Schroers
- 会议/期刊：arXiv preprint
- 年份：2024
- 链接：https://arxiv.org/abs/2404.14967
- 文件路径：papers/2404.14967_CoARF.pdf (待下载)

## 一句话总结
可控的 3D 艺术风格迁移方法，针对辐射场（NeRF）实现细粒度的风格控制。

## 研究问题
- 现有 3D 艺术风格迁移方法（如 ARF）缺乏细粒度控制
- 用户无法精确控制风格应用的空间区域和强度
- 需要一种支持局部控制和多风格融合的 3D 风格迁移框架

## 核心思想
- 基于 NeRF 的风格迁移架构
- 引入空间控制机制，支持局部风格应用
- 可能使用 mask 或 prompt 来控制风格区域

## 方法概述
- 在 ARF 基础上增加控制模块
- 支持多风格输入和空间选择
- 保持 3D 一致性的风格迁移

## 方法细节
### 1. 输入
- 3D 场景（多视角图像或 NeRF）
- 风格参考图像（可多个）
- 空间控制信号（mask/brush/文本）

### 2. 主要模块
- NeRF 基础架构
- 风格编码器
- 空间控制模块
- 风格融合模块

### 3. 损失函数
- 风格损失（类似 Gram matrix 或 CLIP 风格损失）
- 内容保真损失
- 多视角一致性损失
- 可能的控制约束损失
