# LayoutDM: Discrete Diffusion Model for Controllable Layout Generation

## 基本信息
- 标题：LayoutDM: Discrete Diffusion Model for Controllable Layout Generation
- 作者：Naoto Inoue, Kotaro Kikuchi, Edgar Simo-Serra, Mayu Otani, Kota Yamaguchi
- 会议/期刊：arXiv preprint
- 年份：2023
- 链接：https://arxiv.org/abs/2303.08137
- 文件路径：papers/2303.08137_LayoutDM.pdf (待下载)

## 一句话总结
基于离散扩散模型的可控布局生成方法，支持多种约束条件下的版面设计。

## 研究问题
- 现有布局生成方法难以同时处理多种约束条件
- 连续扩散模型不适合离散的布局元素（边界框、类别等）
- 需要一种统一框架处理位置、大小、类别等多维约束

## 核心思想
- 使用离散扩散模型（Discrete Diffusion）处理布局数据
- 将布局元素（边界框、类别）建模为离散状态
- 支持多种约束条件的可控生成

## 方法概述
- 离散状态空间的扩散过程
- 条件注入机制支持多种约束
- 单一模型处理多种布局生成任务

## 方法细节
### 1. 输入
- 约束条件（元素类型、位置、数量等）
- 可选的参考布局

### 2. 主要模块
- 离散扩散过程
- 条件编码器
- 布局解码器

### 3. 损失函数
- 离散扩散的交叉熵损失
- 约束满足损失

### 4. 训练流程
- 在布局数据集上训练
- 支持多种约束条件的条件生成
